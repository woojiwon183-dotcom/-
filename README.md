# ♻️ Project

# Arduino 기반 스마트 자동 분리수거 시스템

## 프로젝트 한 줄 소개

> **Arduino와 다양한 센서 및 모터를 활용하여 폐기물을 자동으로 감지하고 분류하는 소형 스마트팩토리 시스템**

---

## 프로젝트 개요

우리 팀은 Arduino를 활용하여 단순한 센서 제어 실습을 넘어,
실제 스마트팩토리에서 사용되는 **감지 → 판단 → 이송 → 분류 → 데이터 관리** 과정을 하나의 시스템으로 구현하고자 합니다.

초기 아이디어는 **쓰레기 자동 분리수거 시스템**에서 시작했습니다.

폐기물을 한곳에 투입하면 센서가 정보를 수집하고,
Arduino가 데이터를 판단한 후,
컨베이어와 서보모터를 이용하여 폐기물을 종류별 수거함으로 자동 분류하는 시스템을 제작합니다.

최종적으로는 단순한 분리수거 장치를 넘어

> **환경 문제 + Arduino + 자동화 + 스마트팩토리 + 교육**

을 결합한 프로젝트로 발전시키는 것을 목표로 합니다.

# 💡 Project Background

## 1. 환경에 대한 관심

우리 팀은 평소 환경문제와 기업들의 **탄소중립 및 ESG 경영**에 관심을 가지고 있었습니다.

기업들이 환경을 보호하고 자원순환을 실현하기 위해 다양한 기술을 활용하고 있는 상황에서,
Arduino 수업을 통해 단순한 실습을 넘어

> **"Arduino를 활용하여 실제 환경문제를 해결할 수 있는 프로젝트를 만들어보자."**

라는 생각을 하게 되었습니다.

---

## 2. 부산에서 발견한 문제

부산은 국내외 관광객이 많이 방문하는 대표적인 관광도시입니다.

부산시 자료에 따르면 **2024년 부산을 방문한 외국인 관광객은 2,929,192명**으로,
2023년 1,820,057명보다 **60.9% 증가**했습니다.

관광객이 증가하면서 관광지의 환경관리와 폐기물 관리 역시 중요해지고 있다고 판단했습니다.

우리 팀은 부산의 관광지를 생활하면서 경험하는 과정에서
쓰레기통이 가득 차 있거나 주변에 쓰레기가 쌓여 있는 모습을 접했고,
이러한 환경이 도시의 미관을 저해할 수 있다는 점에 주목했습니다.

특히 사람들이 분리수거를 할 때

- 폐기물의 재질을 직접 판단해야 하고
- 여러 종류의 쓰레기를 직접 분류해야 하며
- 분리배출 과정 자체를 번거롭게 느낄 수 있다는 점

에서 문제를 발견했습니다.

그래서 다음과 같은 질문에서 아이디어를 시작했습니다.

> ### **"쓰레기를 한곳에 모아놓더라도 기계가 자동으로 분류해줄 수 있다면 환경에 도움이 되지 않을까?"**

이러한 생각을 Arduino의 센서와 모터, 자동화 기술과 결합하여
**자동 분리수거가 가능한 미니 스마트팩토리**를 제작하는 것으로 발전시켰습니다.

---

# ❓ Problem Definition

현재 분리배출은 사용자가 폐기물의 종류와 재질을 판단하여
각각의 수거함에 직접 배출하는 방식이 일반적입니다.

하지만 실제 환경에서는 다음과 같은 문제가 발생할 수 있습니다.

### ① 분리배출의 번거로움

사용자가 폐기물의 종류를 직접 확인하고 분류해야 합니다.

### ② 잘못된 분리배출

서로 다른 종류의 폐기물이 섞이면 추가적인 선별 과정이 필요할 수 있습니다.

### ③ 반복적인 선별 작업

폐기물 선별은 반복적인 작업이 필요하며,
산업 현장에서는 이를 자동화하기 위한 AI·로봇 기술이 개발되고 있습니다.

### ④ 교육 측면의 문제

스마트팩토리와 자동화 기술을 이론으로 배우는 것과
실제로 센서와 모터를 연결하여 자동화 공정을 만들어보는 것에는 차이가 있습니다.

# 🔄 Idea Development

처음에는 실제 생활환경에서 사용할 수 있는
**자동 분리수거 장치**를 만드는 것을 목표로 했습니다.

하지만 시장조사를 통해 이미 국내에는
AI, IoT, 로봇 등을 활용한 폐기물 관리 및 자동 선별 기업들이 존재한다는 것을 확인했습니다.

따라서 기존 기업들과 동일한 시장에서 직접 경쟁하기보다는
아이디어를 다음과 같이 발전시켰습니다.

```text
환경문제에 대한 관심
        ↓
부산 관광지의 폐기물 문제
        ↓
자동 분리수거 아이디어
        ↓
국내 시장조사
        ↓
기존 기업의 높은 기술력 확인

        ↓

        ↓
학생들이 직접 만들어보고 배우는 제품

# 3. 에이트테크 - 에이트론(ATRON)

## 제품 및 기술

에이트론은 **AI 기반 폐기물 선별로봇**입니다.

비전센서를 통해 폐기물을 인식하고,
AI가 폐기물의 재질과 종류를 판단한 뒤
로봇이 지정된 위치로 폐기물을 이동시키는 방식입니다.

### 주요 성능

| 항목 | 에이트론 |
|---|---:|
| 객체 인식 정확도 | **99.3%** |
| 선별 처리량 | **분당 최대 96개** |
| 대상 폐기물 | **9종** |

폐기물 투입
     ↓
IR 센서
     ↓
물체 감지
     ↓
컨베이어 ON
```

## 3. 인덕티브 근접센서

금속 물체를 감지합니다.

```text
🥫 캔
 ↓
인덕티브 센서
 ↓
금속 감지
 ↓
Arduino
 ↓
금속 분류
```

> ⚠️ 사용하는 인덕티브 센서의 전원 전압과 출력 방식이 Arduino와 호환되는지 반드시 확인합니다.
> 산업용 센서는 별도의 전원 및 신호처리가 필요할 수 있습니다.

---

## 4. TCS34725 컬러센서

RGB 값을 측정하여 추가적인 분류 정보를 제공합니다.

> ⚠️ 컬러센서만으로 플라스틱이라는 재질을 정확하게 판별할 수 있는 것은 아닙니다.
> 초기 프로젝트에서는 제한된 테스트 조건에서 추가적인 분류 정보로 활용합니다.

컨베이어

# 🧪 Testing

## 테스트 대상

프로토타입에서 다음과 같은 테스트 물체를 사용합니다.

| 테스트 물체 | 예상 분류 |
|---|---|
| 알루미늄 캔 | 금속 |
| 철제 캔 | 금속 |
| 플라스틱 병 | 플라스틱 |
| 플라스틱 용기 | 플라스틱 |
| 종이류 | 기타 |
| 테스트용 기타 물체 | 기타 |

> 실제 폐기물은 오염, 형태, 색상, 크기 등에 따라 센서 결과가 달라질 수 있으므로
> 초기 테스트에서는 크기와 형태가 일정한 교육용 테스트 물체를 사용합니다.

---

## 정확도 측정 방법

예를 들어 총 100개의 테스트 물체를 투입합니다.

```text
총 테스트 수 = 100개
정확하게 분류 = 92개
잘못 분류 = 8개
```

정확도는 다음과 같이 계산합니다.

```text
분류 정확도(%)
=
정확하게 분류한 개수
÷
전체 테스트 개수
× 100
```

예:

```text
92 ÷ 100 × 100 = 92%
```

# ⚠️ Limitations

현재 프로토타입에는 다음과 같은 한계가 있습니다.

### 1. 센서 기반 재질 판별의 한계

금속은 인덕티브 센서를 이용하여 비교적 명확하게 감지할 수 있지만,
플라스틱과 종이 등의 재질을 단순한 색상 정보만으로 정확하게 구분하기는 어렵습니다.

### 2. 제한적인 분류 종류

초기 버전에서는 금속 / 플라스틱 / 기타의
제한된 분류만 구현합니다.

### 3. 산업용 시스템과의 성능 차이

실제 산업현장에서 사용되는 AI·비전·로봇 시스템과 비교하면
처리속도와 분류 정확도에 차이가 있을 수 있습니다.

### 4. 실제 폐기물 환경과의 차이

실제 폐기물은

- 찌그러짐
- 오염
- 색상 차이
- 크기 차이
- 겹침
- 다양한 재질

등으로 인해 센서가 오작동할 수 있습니다.

# 💡 GROUND의 핵심 가치

우리의 프로젝트는 단순히

> **"쓰레기를 자동으로 분리하는 기계"**

를 만드는 것이 아닙니다.

우리는 하나의 폐기물이 이동하는 과정을 통해

```text
감지
 ↓
판단
 ↓
이송
 ↓
분류
 ↓
데이터 수집
 ↓
관리
```

라는 **스마트팩토리의 기본적인 자동화 공정**을 직접 구현하고자 합니다.

따라서 이 프로젝트의 핵심은

> **환경문제를 해결하는 과정에서 미래의 자동화 기술을 배우는 것**

입니다.
