# ♻️ Project

## Arduino 기반 스마트 자동 분리수거 시스템

### 프로젝트 개요

Arduino와 다양한 센서 및 모터를 활용하여
**폐기물을 자동으로 감지하고 분류하는 소형 스마트 분리수거 시스템**을 제작합니다.

단순히 쓰레기를 수거하는 것에서 끝나는 것이 아니라,

> **감지 → 판단 → 분류 → 데이터 수집**

의 자동화 과정을 구현하는 것을 목표로 합니다.

이를 통해 실제 스마트팩토리에서 사용되는
**센서, 제어, 자동화, 데이터 관리 기술**을 직접 경험하고 학습합니다.

# 💡 Why Smart Recycling?

## 문제 정의

현재 분리수거는 사용자가 폐기물의 재질과 종류를 직접 판단하여
올바른 장소에 배출해야 합니다.

하지만 실제 환경에서는

- 재질을 정확하게 구분하기 어려움
- 분리배출 방법을 잘 모르는 경우가 있음
- 잘못된 분리배출로 인한 재활용 효율 저하
- 반복적인 분류 작업에 많은 인력과 시간이 필요

등의 문제가 발생할 수 있습니다.

따라서 사용자가 폐기물을 투입하면
**시스템이 자동으로 종류를 판단하고 분류하는 방식**을 제안합니다.

# ⚙️ System Concept

초기에는 폐기물을 **3종류 정도**로 단순화하여 구현합니다.

예시:

```text
                 [폐기물 투입]
                       ↓
                  [물체 감지]
                       ↓
                [센서 데이터 측정]
                       ↓
                  [Arduino 판단]
                       ↓
              ┌────────┼────────┐
              ↓        ↓        ↓
             PET      CAN     OTHER
              ↓        ↓        ↓
           수거함 A  수거함 B  수거함 C


https://chatgpt.com/share/6a7c04c2-19a8-83ee-b2cd-c75ddf5e5cbb
AI와 아두이노 연동 스마트 분리수거 키트는 **[PC 웹캠(AI 이미지 인식) → 시리얼 통신 → 아두이노(서보모터 제어)]** 파이프라인으로 구성하는 것이 학생 수준에서 가장 직관적이고 구현 성공률이 높습니다.

**주요 구성 부품 및 역할**

* **AI 및 카메라 (SW):** Google Teachable Machine 또는 Python OpenCV + TensorFlow Light (PC 웹캠 활용)
* **메인 컨트롤러 (HW):** 아두이노 우노(Arduino Uno)
* **액추에이터 및 센서:** 서보모터(SG90, 분류 가이드 제어), 초음파 센서(물체 도착 감지), RGB LED/부저(상태 알림)

1. **1. AI 학습 데이터 구축:** Google Teachable Machine 활용.
구글 Teachable Machine 이미지 프로젝트를 이용해 플라스틱, 캔, 종이, 일반쓰레기 항목별로 30~50장씩 웹캠으로 데이터셋을 촬영하고 학습시킵니다.


2. **2. 시리얼 통신 연동:** PC to Arduino Serial.
AI 분류 결과(예: 플라스틱='1', 캔='2', 종이='3')를 PC의 웹브라우저(p5.js) 또는 파이썬 스크립트를 통해 아두이노 시리얼 포트로 송신합니다.


3. **3. 아두이노 제어 회로 구성:** 서보모터 수거함 제어.
아두이노가 시리얼 신호('1', '2', '3')를 수신하면 서보모터 각도(예: 45°, 90°, 135°)를 조절하여 해당하는 분리수거 칸으로 쓰레기가 들어가도록 회로를 구동합니다.


4. **4. 키트 외형 및 메커니즘 제작:** 하드웨어 프레임 결합.
폼보드나 3D 프린팅 프레임 위에 경사로와 서보모터 회전판을 장착하여, 입력된 쓰레기가 자동으로 분류함에 떨어지는 구조물을 완성합니다.


**교육적 활용 포인트**

* **데이터 인공지능 이해:** 찌그러진 캔이나 투명한 페트병처럼 AI 인식 오차가 생기는 사태를 관찰하며 데이터 품질과 분류 한계를 직접 확인해 볼 수 있습니다.
* **피지컬 컴퓨팅 실습:** 소프트웨어의 판단(AI)이 실제 물리적 움직임(모터 제어)으로 이어지는 센서-액추에이터 연동 과정을 학습합니다.
